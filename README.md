## Rinat Tainov

Staff AI Engineer in Amsterdam. Fifteen years on the data layer under two-sided
marketplaces — ingestion, ranking, experimentation, and the observability that
tells you whether any of it worked.

In 2018 I built visual similarity search over tens of millions of listings, back
when the libraries existed but the vector databases didn't. A few years later I
was writing telemetry schemas before OpenTelemetry had settled the argument. Both
of those are things you can buy now. That's the pattern I find most useful:
when a capability commoditises the work doesn't disappear, it migrates — and
the job is keeping an accurate map of where it went.

Right now that map points at AI agents. Not the models: the layer underneath
them. What did the agent actually do, what did it cost, and was the output any
good.
